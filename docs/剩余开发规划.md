### 第一步 🔴 浏览器自动化 + MiMo/商汤适配器

**做什么**：应用内置一个独立浏览器（Chromium），你**首次**在弹窗里手动登录一次 MiMo，之后程序自动提取并刷新 Cookie、自动抓余额，不再要你手动看。

**为什么能做快**：MiMo 的两个接口现成（Python 原型里已有）：
- 现金余额：`https://platform.xiaomimimo.com/api/v1/balance` → `data.balance` / `cashBalance` / `giftBalance`
- Token Plan：`https://platform.xiaomimimo.com/api/v1/tokenPlan/usage` → `data.usage.items[]`

缺的只有「自动拿 Cookie」这一步。

**关键设计**（按你的决定）：
- 不存账号密码；只存登录后的 Cookie。
- Cookie 约 24 小时过期 → 程序检测到失败，弹窗提示你重新登录一次。
- 后续接商汤 SenseNova（同套路，接口需现场抓一次包）。

**代价**：安装包增大约 150MB（内置 Chromium）。

### 第二步 🔴 安装包 + 系统托盘

- 用 electron-builder 打成 `.exe` 安装包（双击安装）。
- 点 × 不退出，缩到右下角托盘继续后台监控。
- 开机自启。

### 第三步 🟡 成本折算（联网汇率）+ 趋势图

- 成本折算：请求公开免费汇率接口（只发货币代码 USD/CNY，**不带任何账号信息**），给一个「合计约 ¥xxx」。
- 用量趋势折线图：数据已落盘，补个图即可。

### 第四步 🟢 其余体验

## 四、二期第一刀的具体方案（从 MiMo 开始）

1. 引入 Playwright + 独立 Chromium。
2. 新增账号类型 `mimo` / `mimo_plan`（界面里选「小米 MiMo」）。
3. 首次点「登录 MiMo」→ 弹出内置浏览器 → 你手动登录 → 程序提取 Cookie 存起来（加密）。
4. 之后定时用 Cookie 调那两个接口自动抓余额。
5. Cookie 过期 → 卡片标红提示「重新登录」。

**开工前需要你提供**：一个能登录 MiMo 的账号（首次手动登录用），我拿到后跑通整条链。
