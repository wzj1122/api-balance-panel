# 主题设计指南（把这份交给设计类 AI 即可）

> 目标：为「API 余额面板」设计主题配色。你只需要输出 CSS 变量，不需要写任何组件代码。

## 一、机制（为什么只要给变量）

- 所有颜色都走 CSS 变量，组件里没有硬编码颜色。切主题 = 换一组变量。
- 默认（无 data-theme）是**浅色**；深色用 `[data-theme="dark"]` 覆盖。
- 新增一套主题：只要再写一个 `[data-theme="主题名"] { ...颜色... }` 块，其余代码零改动。
- 尺寸、圆角、字号、动效是共享 token，不要在主题里改。

## 二、必须输出的变量清单（缺一个就会有元素不好看）

**背景层级（由深到浅/由底到面）**
- `--bg-0` 窗口最底层（body 背景，带径向光晕）
- `--bg-1` 内容区底色
- `--bg-2` 输入框聚焦态底色
- `--panel` 弹窗/浮层底色
- `--panel2` 次级块、悬停底、标签底
- `--card` 卡片底色
- `--card-hover` 卡片/表格行悬停底色
- `--card-grad` 卡片背景（可以是纯色或 180deg 渐变）
- `--modal-bg` 弹窗背景（纯色或渐变）

**描边**
- `--line` 常规分隔线；`--line-strong` 强调描边（悬停/聚焦）；`--line-soft` 极淡分隔（表格行）

**文字**
- `--tx` 正文；`--tx-strong` 标题与关键数字；`--tx2` 次要说明；`--tx3` 弱化/占位

**语义色（每个都要配一个 -soft 半透明底）**
- 成功 `--ok` / `--ok-soft`
- 警告 `--warn` / `--warn-soft`
- 危险 `--err` / `--err-soft`，另有 `--err-bg`（错误卡片整块底色）

**品牌色**
- `--acc` 主色（按钮/链接/进度/选中态）
- `--acc-2` 辅助色（渐变第二色、次要高亮）
- `--acc-grad` 主渐变（如 `linear-gradient(135deg, 主色, 辅助色)`）
- `--acc-soft` 主色 12%~18% 透明底（选中态、信息条）

**特殊面**
- `--bar-bg` 标题栏/侧边栏（半透明，下面有模糊，建议 0.7 左右不透明度）
- `--bar-bg-soft` 更淡的浮层底（表头、脚注）
- `--track` 进度条/滑块轨道
- `--scroll-thumb` / `--scroll-thumb-hover` 滚动条

**阴影**
- `--shadow-sm` 卡片投影；`--shadow` 弹窗投影；`--shadow-glow` 主色发光（按钮/logo）

**平台品牌色（9 个，一般不用改，保持各平台辨识度）**
- `--p-deepseek` `--p-siliconflow` `--p-newapi` `--p-custom` `--p-mimo` `--p-aliyun` `--p-mimo-plan` `--p-minimax` `--p-zhipu`

## 三、设计约束（重要）

1. **对比度**：正文 `--tx` 对 `--bg-1` ≥ 4.5:1；标题/数字 `--tx-strong` ≥ 7:1；`--tx2` ≥ 3:1。
2. **层级关系**：`bg-0` → `bg-1` → `card` → `panel2` 要有可感知但克制的明度差（深色主题相邻层级差 4%~8% 明度，浅色 2%~4%）。
3. **不要纯黑纯白大面积**（#000 / #fff 只用于按钮文字）。
4. **语义色不做装饰**：绿=正常、黄=注意、红=异常，不要拿它们当主题色。
5. **深浅双份**：每套主题请给「深色版 + 浅色版」两组，内容一致。
6. **`--bar-bg` 必须半透明**（它下面有模糊与滚动内容），否则顶栏会显得死板。
7. 表格存在**斑马纹**（用 `--line-soft`）与**冻结首列**（底色用 `--card`），别让它们看不清。

## 四、提示词模板（直接复制）

```
你是资深 UI 设计师兼前端工程师。请为一个「API 余额监控面板」桌面应用设计主题配色。

应用特征：深色为主的开发者工具，界面包含：顶部标题栏、左侧导航、账号余额卡片网格、
数据表格、日历热力图、折线/柱状图、进度条、弹窗表单、系统托盘。文字以中文为主，数字较多。

技术约束：所有颜色必须通过 CSS 变量输出，不要写组件代码、不要引入新依赖。
默认浅色写在 :root，深色写在 [data-theme="dark"]；新增主题写在 [data-theme="主题名"]。

请输出以下变量（每个都要给值）：
--bg-0 --bg-1 --bg-2 --panel --panel2 --card --card-hover --card-grad --modal-bg
--line --line-strong --line-soft
--tx --tx-strong --tx2 --tx3
--ok --ok-soft --warn --warn-soft --err --err-soft --err-bg
--acc --acc-2 --acc-grad --acc-soft
--bar-bg --bar-bg-soft --track --scroll-thumb --scroll-thumb-hover
--shadow-sm --shadow --shadow-glow

要求：① 正文对比度 ≥ 4.5:1，标题 ≥ 7:1；② 背景层级差克制（深色 4%~8% 明度）；
③ 不用纯黑纯白做大面积底色；④ 语义色只表达状态；⑤ --bar-bg 半透明；
⑥ 输出格式为可直接粘贴的 CSS 代码块，每个变量后加一行中文注释说明用途。

主题方向：<在这里填你要的风格，例如「深夜蓝 + 青绿点缀，冷静专业」>
```

## 五、可选的 4 个方向（可直接挑一个填进模板）

| 主题 | 气质 | 主色建议 |
|---|---|---|
| 极简白 | 清爽、纸张感、适合白天办公 | 石墨灰 + 单一蓝点缀 |
| 深夜蓝 | 冷静专业（当前默认风格） | 深蓝灰底 + 蓝青渐变 |
| 森林绿 | 温和护眼、低饱和 | 墨绿底 + 薄荷绿点缀 |
| 赛博紫 | 科技感、夜间使用 | 近黑底 + 紫粉渐变 + 霓虹高亮 |
| 暖砂棕 | 温暖、纸质感、长时间阅读友好 | 米棕底 + 陶土色点缀 |

## 六、交付与接入

拿到设计后，把每组变量发我即可，我会：
1. 在 `app/src/renderer/src/styles/variables.css` 追加 `[data-theme="xxx"]` 块；
2. 设置页主题选项自动多出一项（显示名可中文）；
3. 跑一遍对比度与浅色/深色实测截图确认后打包。
